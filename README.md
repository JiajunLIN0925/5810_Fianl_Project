# 5810 Final Project

This repository contains the final project files for the 5810 course project.  
The project focuses on analyzing the impact of game-related accident events on game performance indicators using event-window analysis and fixed-effects regression.

## Project Overview

This project uses game operation data and accident event data to study whether different types of accident events affect key game performance metrics, including revenue, daily active users, downloads, RPD, and ARPDAU.

The analysis mainly includes:

- Raw data cleaning and preprocessing
- Matching accident events with game operation data
- Constructing event windows before and after accident dates
- Before-after descriptive comparison
- Fixed-effects regression analysis
- Subsample analysis by accident type
- Regional heterogeneity analysis for selected markets
